# BarberFlow 💈
Sistema Web de Gerenciamento de Agendamentos para Barbearias

## 1. Sobre o Projeto

O BarberFlow é um sistema web que tem como objetivo facilitar o agendamento de serviços em barbearias, permitindo que os clientes escolham o barbeiro, o serviço, a data e o horário desejados.

O sistema busca reduzir o tempo de espera dos clientes e facilitar a organização dos atendimentos diários dos barbeiros.

## 2. Nicho de Atuação

O projeto está inserido no setor de beleza e cuidados pessoais, com foco em barbearias que desejam organizar seus agendamentos por meio de uma plataforma digital simples e acessível.
